# 🚗 Telegram-бот «Авто-ассистент водителя» (Все-в-одном)

Полнофункциональный асинхронный Telegram-бот на **Python 3.11+**, созданный с использованием **aiogram 3.x** и **aiosqlite**.

---

## 🌟 Основные возможности

1. **🛰 Живая геолокация (Live Location):**
   - Прием как разовых геометок, так и непрерывных потоковых обновлений геолокации (`edited_message(F.location)`).
   - Сохранение актуальных координат в базу данных SQLite.
   - **Автоматическое предупреждение:** бот непрерывно проверяет расстояние по **формуле Хаверсина** и отправляет звуковое/текстовое оповещение при приближении к опасному участку, экипажу ДПС, аварии или дорожным работам ближе **500 метров** (с защитой от повторного спама в течение 15 минут).

2. **⚠️ Народная карта (User-Generated Content):**
   - Кнопка «Сообщить о событии» с выбором категорий: *💥 ДТП, 🚧 Ремонт дороги, 👮 Экипаж ДПС, ❄️ Гололед*.
   - Пошаговый FSM-сценарий (выбор категории ➔ отправка геометки ➔ комментарий).
   - Автоматическая рассылка предупреждения всем активным водителям в радиусе **5 км**.

3. **📰 Новости и сводки ГАИ/Автоинспекции:**
   - Раздел «Новости ГАИ» с просмотром последних предупреждений (рейды, изменения правил, перекрытия).
   - Защищенная панель администратора (`/admin` или `/add_news`) с возможностью публикации и экстренной рассылки всем пользователям.

4. **🚨 Помощь рядом (Экстренные службы):**
   - Поиск ближайшего круглосуточного шиномонтажа или эвакуатора относительно текущих координат водителя.
   - Расчет точного расстояния, вывод контактных телефонов и прямых ссылок на карты.

5. **⏰ Напоминания (ОСАГО, ТО, Замена масла):**
   - Запись дат окончания действия документов с валидацией формата.
   - Фоновый асинхронный планировщик: автоматическая отправка уведомления **за 7 дней** и **в день окончания** полиса/диагностической карты.

## 🚀 Быстрый старт

### 1. Клонирование / Переход в папку
```bash
cd car_assistant_bot
```

### 2. Создание виртуального окружения
```bash
python -m venv venv

# Активация на Windows:
.\venv\Scripts\activate

# Активация на Linux/macOS:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка файла `.env`
Скопируйте пример настроек:
```bash
cp .env.example .env
```
Откройте файл `.env` и укажите ваш токен бота (от [@BotFather](https://t.me/BotFather)) и ID администратора (узнать можно через [@userinfobot](https://t.me/userinfobot)):
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_IDS=123456789
DB_PATH=bot_database.sqlite3
DANGER_RADIUS_METERS=500.0
BROADCAST_RADIUS_METERS=5000.0
```

### 5. Запуск бота
```bash
python main.py
```

## 🧮 Формула Хаверсина

Для вычисления расстояния между координатами пользователя $(\varphi_1, \lambda_1)$ и объектом $(\varphi_2, \lambda_2)$ на поверхности сферы используется соотношение:

$$a = \sin^2\left(\frac{\Delta \varphi}{2}\right) + \cos(\varphi_1) \cdot \cos(\varphi_2) \cdot \sin^2\left(\frac{\Delta \lambda}{2}\right)$$
$$c = 2 \cdot \operatorname{atan2}\left(\sqrt{a}, \sqrt{1-a}\right)$$
$$d = R \cdot c$$

где $R = 6\,371\,000\text{ м}$ — средний радиус Земли. Данный алгоритм реализован в модуле `utils/geo.py` с детальными комментариями.
